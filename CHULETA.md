# Mi chuleta de git
- `git status`: qué ha cambiado
- `git add <fichero>`: prepara un fichero para el commit
- `git commit -m "mensaje"`: guarda lo preparado en un commit
- `git diff`: lo que has cambiado y aún no has preparado
- `git diff --staged`: lo que ya está preparado
- `git log --oneline`: el historial, un commit por línea
- `git commit -am "mensaje"`: add y commit de lo ya seguido
git restore --staged <nombre del archivo> , lo saca de seguimiento
rm <nombre del archivo> lo borra del fichero
-`git restore <fichero>` : descarta lo que nos has guardado
- `git restore <fichero>`: descarta lo que no has guardado
- Atajos de teclado: mira ATAJOS.md
- `git push --force`: la mejor forma de subir cambios
